# 快速开始与配置

## 1. 环境准备

建议使用 Python 3.14，并安装 `requests`；还需要能够访问 Bilibili API 的网络环境。Obsidian 不是脚本运行的硬依赖，但生成的链接和目录按 Obsidian 的使用方式设计。

```powershell
python -m pip install requests
```

仓库目前没有依赖清单或命令行参数。脚本中的配置路径是相对于当前工作目录的路径，请始终在仓库根目录运行。

Python 3.13 及更早版本可能在导入 `webapi.py` 时遇到类型注解兼容问题，详见[已知问题](known-issues.md#python-版本兼容)。

## 2. 配置 Cookie

复制示例文件：

```powershell
Copy-Item "功能性文件/cookies.example.md" "功能性文件/cookies.md"
```

把 `cookies.md` 的整行内容替换为自己已登录 Bilibili 后的 Cookie。该文件会原样写入 HTTP 请求头，因此不要添加 Markdown 标题、代码围栏或说明文字。

`功能性文件/cookies.md` 已被 `.gitignore` 忽略。Cookie 等同于登录凭据，不要提交到 Git、粘贴到 Issue 或放入运行日志。

## 3. 选择收藏夹

编辑 `功能性文件/Python脚本设置.md` 中的这一段：

```markdown
## B站同步文件夹

- [ ] 电影
- [ ] 体育

## 本地视频同步文件夹
```

当前解析规则有以下要求：

- `## B站同步文件夹` 后必须存在另一个 `##` 二级标题，用于结束配置区段。
- 每个项目必须写成 `- [ ] 名称`；`- [x]` 不会被当作正常的收藏夹名称解析。
- 空格和换行会在解析前被删除。
- 远端收藏夹名称会被清洗为“只保留基本汉字”。配置名称必须与清洗后的名称一致。
- 两个清洗后同名的收藏夹会相互覆盖。

`本地视频同步文件夹` 和 `关注的UP` 目前不会参与 `scripts/main.py` 的同步流程。

## 4. 设置完整合集

`功能性文件/全收藏合集.md` 每行填写一个合集名称：

```text
初中培优
高效听力训练
```

- 在列表中：为合集内所有视频创建笔记，并放入合集的 `笔记/` 目录。
- 不在列表中：只为当前收藏夹中被单独收藏的视频创建笔记，其余条目保留为网页链接。

合集名称需要与 Bilibili 返回并经 `xreplace()` 清洗后的名称完全一致。不要保留只含空格的行；当前读取器只跳过真正的空行。

## 5. 执行同步

在仓库根目录运行：

```powershell
python scripts/main.py
```

脚本会读取配置、访问 Bilibili、扫描已有笔记、创建或移动 Markdown，并在最后覆盖写入 `功能性文件/infoDict.json`。

同步前建议备份 `B站视频/`。项目当前没有预演模式，完整合集处理可能移动、改名和重写已有文件。若脚本启动失败或结果异常，先查看[已知问题与安全提示](known-issues.md)。
