# 文档导航

文档按使用者和维护者关心的问题拆分。首次使用按下面的顺序阅读即可。

| 文档 | 内容 | 适合读者 |
| --- | --- | --- |
| [快速开始与配置](getting-started.md) | 环境、Cookie、收藏夹选择、启动方式 | 所有用户 |
| [数据与输出格式](data-and-output.md) | 目录结构、笔记格式、缓存数据 | 使用者、主题开发者 |
| [架构与同步流程](architecture.md) | 模块职责、对象关系、执行顺序 | 维护者 |
| [同步关系图](关系图.canvas) | 可在 Obsidian 中打开的执行关系图 | 维护者 |
| [模块 API](api.md) | 当前函数、参数、返回值和副作用 | 维护者 |
| [已知问题与安全提示](known-issues.md) | 当前限制、风险和排查入口 | 所有用户 |
| [实现备忘](细节实现.md) | 设计约束和后续重构关注点 | 维护者 |

文档以当前工作区的 `scripts/` 实现为准。这个项目尚未发布为 Python 包，也没有稳定的公共 API；重构函数时应同步更新这里的说明。
